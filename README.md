# HR Analytics Dashboard

## Project Overview

This Power BI project explores employee and workforce data to better understand employee demographics, attrition, salary levels, job roles, satisfaction, and employee tenure.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

## Key Metrics

- Total Employees
- Attrition
- Average Age
- Average Salary
- Average Years at Company
- Job Satisfaction
- Salary Slabs
- Job Role Distribution

## Analysis Areas

- Attrition by Education
- Employees by Age Group
- Salary Distribution
- Years at Company
- Job Roles
- Gender Distribution
- Job Satisfaction
