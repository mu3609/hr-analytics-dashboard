# HR Analytics Dashboard

## Project Overview

This project uses Power BI to analyze employee and workforce data across attrition, demographics, salary levels, job roles, job satisfaction, and employee tenure.

## Business Problem

The objective was to transform HR data into an interactive dashboard that helps users understand workforce trends and identify areas that may require further investigation.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel
- Data Cleaning
- Data Visualization

## Data Cleaning & Preparation

- Checked the dataset for missing and inconsistent values.
- Verified field data types.
- Prepared and transformed data using Power Query.
- Organized categorical employee information for reporting.
- Created measures and calculated fields where required.

## Key KPIs

- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Salary
- Average Years at Company

## Analysis Areas

- Attrition by Education
- Employees by Age Group
- Gender Distribution
- Salary Distribution
- Employee Tenure
- Job Role Distribution
- Job Satisfaction

## Key Observations

- Attrition can be compared across different employee groups.
- Age-group analysis provides insight into workforce demographics.
- Salary-band analysis shows employee distribution across compensation ranges.
- Job-role analysis provides visibility into workforce composition.
- Tenure analysis helps understand employee retention patterns.
- Job satisfaction can be evaluated across different job roles.

## Business Recommendations

- Investigate roles with relatively high employee attrition.
- Compare attrition with salary and employee tenure.
- Monitor job satisfaction alongside retention metrics.
- Review workforce demographics for future hiring and succession planning.
- Identify employee groups that may require targeted retention strategies.
